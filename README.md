# CMS_SCHET — Приём счетов от контрагентов

Веб-приложение на Flask для приёма счетов от контрагентов (поставщиков)
ООО «ФОРЭС» с открытой формой загрузки и защищённой админ-панелью.

## Возможности

- **Открытая форма** (`/`) — контрагент заполняет данные счёта и прикладывает
  файл (PDF/скан). Поля совпадают с «Реестром платежей»: № счёта, дата,
  контрагент, товар/услуга, сумма, примечание, назначение (подразделение), файл.
- **Админ-панель** (`/admin`) — список счетов, поиск, фильтр по статусу,
  изменение статуса («новый» → «в обработке» → «оплачен» / «не учитывать»),
  скачивание файлов, удаление.
- **Экспорт в PDF** (`/admin/export`) — единый PDF-реестр всех счетов,
  совместимый по составу полей с существующим «Реестром платежей».
- **Безопасность**: хеширование пароля админа, honeypot-поле против спама,
  ограничение размера и формата файлов, экранирование вывода (Jinja autoescape),
  `secure_filename`-эквивалентная очистка имён файлов.

## Настройка

1. Скопируйте `.env.example` в `.env` и задайте пароль администратора:

   ```powershell
   Copy-Item .env.example .env
   ```

   Обязательно задайте `ADMIN_PASSWORD` (мин. 8 символов).

2. Запуск:

   ```powershell
   C:\Python314\python.exe app.py
   ```

   Сайт откроется на `http://127.0.0.1:5000`.

## Структура

```
CMS_SCHET/
├── app.py            # маршруты: форма, админка, экспорт
├── models.py         # модель Invoice (SQLAlchemy)
├── config.py         # конфигурация (env)
├── templates/        # index, success, login, admin/
├── static/style.css  # стили
├── instance/         # SQLite-БД (создаётся автоматически)
├── uploads/          # загруженные файлы счетов
└── exports/          # сгенерированные PDF-реестры
```

## Справочники

- Контрагенты и подразделения задаются списками `CONTRAGENTS` и `SUBDIVISIONS`
  в `app.py` (синхронизировано со справочниками «Реестра платежей»).
